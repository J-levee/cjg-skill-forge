# 触发词与 SEO 描述规范（Trigger Keywords & SEO Description Guide）

> **定位**：锻造炉产出技能的「被发现」方法论。触发词是技能的生命线——它同时服务两类读者：
> ① **Agent 触发**：description + 「何时使用」表决定 AI 在什么对话下调用本技能；
> ② **用户搜索**：触发词 = 用户在技能平台搜索时的关键词，是**自然流量（SEO）**的来源。
> 两者一体两面：写触发词时同时想"用户会怎么搜"和"AI 会怎么判"。
> **描述长度硬限制：≤1024 字符**（跨平台安装 zip 的兼容线，超长在部分平台导致安装报错）。

---

## 1. 触发词的三层结构

| 层 | 定义 | 示例（技能锻造炉） | 放哪 |
|---|---|---|---|
| **核心触发词**（5–8 个） | 技能主题本身：这个技能"是什么" | 技能锻造、Skill Forge、技能创建、元技能、meta skill、skill builder | description 必含 ≥3 个；何时使用表第一行 |
| **意图触发词**（5–8 个） | 用户"想做什么"时的说法（含口语） | 打造技能、升级技能、重铸技能、审计技能、整理技能库、给技能打分、做技能 | description 含 ≥3 个；何时使用表逐行 |
| **长尾触发词**（可选） | 场景/组合词，覆盖搜索长尾 | 怎么创建 skill、SKILL.md 怎么写、技能被 AI 读不懂、合并重复技能 | 何时使用表备注列；intro.md 可展开 |

**选择原则**：
- 中英双语都要（中文用户 + Agent 多语言触发）。
- 口语优先：用户**不会**说"元技能"但会问"怎么把两个技能合并"——口语说法必须进表。
- 动词优先：意图词以动词开头（创建/升级/审计/整理/打分…），因为用户搜的是"动作+对象"。
- 从「何时使用」表反推：表里每一行的触发词，应能在 description 里找到影子。

## 2. description 写作公式（≤1024 字符）

```
一句话定位（这是什么 + 给谁用）
→ 核心能力 2–4 条（每条含 1–2 个触发词，自然嵌入不堆砌）
→ 使用场景 1 句（触发词收尾）
→ 边界/不做什么 1 句（可选）
```

**硬规则**：
- **≤1024 字符**（中文按字符计，含标点）。写作后立即校验：`writing_gate.py <技能目录>` 的 W3a。
- **不堆砌**：触发词自然嵌入句子，不列"关键词：a,b,c"清单（description 是给人/AI 读的散文，不是标签页）。
- **displayName 含核心词**：平台列表页显示名称，命中搜索越早越好。
- **何时使用表是触发词的"目录"**：description 说"能做什么"，表说"什么话会触发"——两者词汇互相呼应。

**正反对照**：

| ❌ 无 SEO（功能罗列） | ✅ 有 SEO（触发词嵌入） |
|---|---|
| 本技能提供技能锻造功能，包含版本反馈环、覆盖审计、外部标杆对比、自我迭代、说服、签批、真机验证、审视模式、重铸模式。 | 技能锻造炉 / Skill Forge —— 从零**打造、升级、重铸**一个「全球最牛」的 AI 技能：真实素材覆盖审计、外部标杆对比、自我迭代、生产签批、真机验证；也能**审计、打分、整理**已有技能（含重复技能合并）。当你要**创建技能、改造技能、梳理技能库**时用它。 |

## 3. 「何时使用」表规范（触发词目录）

- 列：`用户意图 | 模式/动作 | 触发词示例`。
- **触发词示例列放口语说法 + 英文**（如 `"做到最牛"、forge、锻造`）。
- 每行至少 1 个核心词 + 2 个意图词；表头含"触发词"字样（Agent 可定位）。
- 触发词与 description **互文**：表里有的词，description 至少出现 3 个。

## 4. 校验门（writing_gate 自动检查，发布前必过）

| 项 | 规则 |
|---|---|
| W3 | description 含 "Use when" + 「何时使用」表存在（原有） |
| W3a | **description ≤1024 字符**（超长 = 跨平台安装 zip 报错风险） |
| W3b | **description 含触发词**：从「何时使用」表抽取触发词，description 中命中 ≥3 个（表词互文） |

**生成助手**：`python scripts/forge-describe.py --skill <技能目录>`（或手动 `--name/--what/--abilities/--triggers`）一键生成 ≤1024 字符的 SEO 描述草稿 + 触发词密度报告——写作起点，再按公式精修。

## 5. 与本技能其它纪律的关系

- 纪律 7（触发精度与渐进披露）：本规范是"触发精度"的 SEO 扩展——不止"触发准确"，还要"能被搜到"。
- 纪律 16（可推广闸门）：intro.md ≤1024 字符同源（平台介绍复用 description 的触发词骨架）。
- 写作规范（skill-writing-guide.md）：本规范与其第 2 章（披露范围）、第 1 章（导航结构）配合——触发词嵌入不违反"只写用户侧"（触发词本身就是用户语言）。
